## Overview

Soundtoys Phase Mistress models four classic phaser hardware units with smooth analog phase shifting and a tempo-synced modulator for musical, evolving phaser effects.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys Phase Mistress** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Four Models** | MXR, Small Stone, and other classic phaser hardware emulations |
| **Tempo Sync** | Modulation rate locking to host BPM with note division selector |
| **Feedback** | Adjustable resonance feedback from subtle notching to intense phasing |
| **Stereo** | Independent left/right modulation for wide stereo phasing effects |
